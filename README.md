# DaEun Cheong — Research Portfolio

빌드 도구나 외부 의존성 없이 동작하는 정적 포트폴리오 사이트입니다.

## 파일 구성

- `index.html`: 사이트 전체 HTML, CSS, JavaScript
- `.nojekyll`: GitHub Pages의 Jekyll 처리 비활성화
- `workflows/deploy.yml`: GitHub Pages 배포 설정

## 수정

사이트 내용과 스타일은 `index.html`에서 관리합니다. 이름, 소개, 연구, 논문, 경력, 연락처 링크를 직접 수정할 수 있습니다.

## 배포

GitHub Pages에서 저장소의 `main` 브랜치와 루트 디렉터리를 배포 대상으로 지정하면 됩니다. 별도의 빌드나 패키지 설치는 필요하지 않습니다.
